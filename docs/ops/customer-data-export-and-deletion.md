## Export

PostgreSQL database `customerops` is named by `POSTGRES_DB`; Prisma uses `DATABASE_URL`. Use an authorized, read-only, workspace-scoped session and bind parameters. The runtime role has row-level security on scoped tables; global control and user tables need explicit predicates. Do not export a full database dump.
